# Bangyi Dage Mini Game Prototype

Day 1 Cocos Creator prototype shell.

## How To Open

1. Open Cocos Creator 3.x.
2. Import/open this `game/` folder as a project.
3. Create a new 2D scene if Cocos does not create one automatically.
4. Add a `Canvas` node.
5. Attach `assets/scripts/Day1LivestreamRoom.ts` to the `Canvas`.
6. Press Preview.
7. Build target: WeChat Mini Game.
8. Open the build output in WeChat Developer Tools.

## Day 1 Scope

- Mobile portrait UI shell.
- No AI.
- No payment.
- No backend.
- No event system yet.
- Buttons only log clicks.

## Target Resolution

`750 x 1334`, portrait.
