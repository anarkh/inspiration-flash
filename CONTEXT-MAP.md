# Context Map

## Contexts

- [Personal Agent](./CONTEXT.md) - helps one user execute everyday tasks through planning, tool use, memory, and confirmation
- [Agent Bridge](./agent-bridge/CONTEXT.md) - connects one AI coding agent to another for independent inspection

## Relationships

- **Personal Agent <-> Agent Bridge**: These are separate contexts. Agent Bridge may provide External Review for selected Personal Agent Task Runs, but it is not the Personal Agent's reasoning core, tool layer, or required execution path.
