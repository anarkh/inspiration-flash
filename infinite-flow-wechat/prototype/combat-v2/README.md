# 战斗 v2 · 对峙布局与时机操作 HTML 原型

从 `infinite-flow-wechat/` 启动静态服务（例如 `python3 -m http.server 8125`），打开
`http://127.0.0.1:8125/prototype/combat-v2/`。无需安装依赖。

本目录是隔离的交互原型：不读游戏状态、不写存档、不调用正式命令。数值只用于观察界面
反馈，正式接入时一律读取领域层结算帧。上一版已落地原型见 `../combat/`。

URL 参数：`?scenario=normal|heavy|focus|danger|talisman|boss`、`?assist`（时机辅助，
窗口放慢 1.7 倍）、`?shot`（隐藏顶部演示栏，便于截图）。

## 相比现版的变化

| 现版问题 | v2 处理 |
| --- | --- |
| 主角约 50px 缩在左下，怪物远在中右，大片空地 | 进入战斗即摆阵：主角左下、怪物右上斜向对峙，人物放大（390 宽：主角 200px、怪物 262px；320 宽：136 / 172px），背景压暗并加对决光区 |
| 我方血量是顶部一行小字，敌方是头顶细条 | 顶部对阵条：双方头像、名字、阶级、等宽血条（掉血时白色残影延迟收缩），中间菱形回合徽记 |
| 意图只在顶部一行红字 | 怪物头侧意图气泡：图标 + 名称 + “反击 12 · 防御 6”；重击时红色脉冲，防御键同步发光并挂“推荐” |
| 6 个同尺寸灰色小按钮，战意是左下一行字 | 右下 92px 主攻击键 + 外圈 3 段战意环；战意满自动变金色“战技”。防御 / 法术 / 雷火符 / 药品以 120px 半径扇形排布；“脱离”移到左下 |
| 战斗中摇杆可走但无意义，另有“靠近互动” | 战斗内收起摇杆与互动键，站位由演出控制 |
| 线条特效、无打击感 | 冲刺残影、刀光描边、命中顿帧（70ms，会心 110ms）、怪物受击闪白与后仰、震屏、伤害数字弹出；敌方反击前扑、爪痕与主角受击变红 |
| 无行动回顾 | 对阵条下方一行战报：“第 1 回合 · 普攻 会心 27 · 反击 12” |

## 时机操作

每回合最多一次时机判定，发生在行动指令提交之前：

- **会心**（攻击 / 战技 / 术法 / 雷火符）：主角冲到敌前（术法、符箓原地蓄力），敌身出现
  收缩白圈与金色目标圈；两圈重合时点击屏幕任意处（或空格 / J），伤害 ×1.5，刀光加一道金色
  交叉斩。
- **完美格挡**（防御）：怪物蓄力泛红，主角身上出现收缩红圈；收拢到目标圈时点击，承伤再减半
  （向上取整），战意额外 +1，护盾转为冰蓝并显示“完美格挡”。
- 不点、点早或点晚都按普通结算，与现版完全一致，不额外惩罚。
- 判定窗口：白圈约 0.95s 从 128px 收到 10px，目标带 ±11px（约 0.18s）；“时机辅助”放慢 1.7 倍。
- 止血丹、归息、镇岳、脱离不触发时机判定。

## 落到正式游戏时的边界（待确认原型后实施）

- 领域层：`combat/act` 命令增加可选 `timing: 'perfect'`，由 `packages/application` 校验，
  `packages/core` 的 `performCombatAction` 在既有伤害 / 承伤结算后应用会心或完美格挡修正；
  字段缺省时结算与 Web oracle 逐字节一致，冻结验收不受影响。判定结果作为玩家输入写入命令，
  回放仍是确定性的。
- Cocos 只负责计时与演出：判定在动作“准备”阶段完成后才提交命令，命中、反击数值继续消费
  `combat.presentation-resolved` 帧，不在 UI 计算伤害。
- 战意、意图、推荐动作、禁用原因全部来自现有 ViewModel；本原型里的 18 / 27 / 12 / 30 等数值
  仅为演示。

## 文件

- `index.html`：结构与语义按钮、原生 dialog。
- `style.css`：对阵布局、扇形操作区、320×568 紧凑档、减少动态效果。
- `app.js`：隔离示例状态、时机判定（`window.__qte` 暴露当前圈半径供截图脚本使用）、SVG 特效与回合演出。
- `proof/`：390×844 与 320×568 截图。

素材全部复用正式 resources：`dungeon-world/demon_tower_1-v1.png`、
`monster-world/fog-lesser-demon-world-v1.png`、`character/reincarnator-walk-v2.png`（帧表取自
`cocos/assets/scripts/ui/hero-walk-atlas.ts` 的右向四帧）、`character/reincarnator-v2.png`、
`monster/fog-lesser-demon-v1.png`；不新增素材。
