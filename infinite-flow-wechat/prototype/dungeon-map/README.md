# 区域地图：先看附近，再看全图

本目录是独立 HTML 视觉与交互原型，尚未接入 Cocos。打开：

- http://127.0.0.1:8125/prototype/dungeon-map/index.html
- 同批原型总览：http://127.0.0.1:8125/prototype/dungeon-ux/index.html

也可直接打开本目录 `index.html`。页面使用普通脚本加载 `fixtures.js`，不依赖本地文件的模块导入或 `fetch` 权限。

默认打开地图。桌面左侧、手机预览下方的工作台可切换 3 个真实章节与 2 个演示进度。它们是为验收构造的状态快照，不是存档、通关记录或新增游戏能力。页面不发出游戏命令，不改变真实游戏状态。

## 设计与操作

1. **附近路线（默认）**：先展示当前位置，再按上、右、下、左展示相邻出口。字号 14–16 px，常规每条路线 69–72 px 高；短屏压缩为 56 px。无需在全图中双向寻找下一步。
2. **区域详情**：点击整条出口查看可达、已清理或受阻原因。受阻原因直接使用生产 `disabledReason`，不在前端猜测章规。
3. **出口标记**：可走的相邻出口可设置一个仅视觉方向标记。点击“返回探索”关闭地图，可查看标记；“区域地图”重新打开。标记不执行移动、传送或自动寻路。
4. **已知全图**：保留真实 6×5 位置与上下左右连接，用符号阅读整体关系。默认总览不强塞 30 个完整名称；点选节点时显示大字详情。点击“放大名称”阅读所有已知名称，图内可以横向与纵向滚动；点击“定位”自动回到当前位置。
5. **未知**：仅显示匿名点位；不显示名称、类别、奖励、节点标识，不能点击。仅绘制两个端点都已知的连接，避免替玩家发现远方路线。
6. **键盘**：Tab 移动；视图切换支持方向键；Escape 收起详情或关闭地图。面板打开时背景场景不可获焦。尊重减少动态效果设置。

## 真实数据出处

三章均是标准探索协议。普通地图为完整 6×5、30 节点、49 条无向物理相邻边。**没有重画成稀疏树图**，没有删改节点或拓扑。

| 演示章节 | 生产定义 | 途中状态 |
| --- | --- | --- |
| 第一章 · 妖塔一层 | `packages/core/src/level-data/demon-tower.ts` | 裂缝石门；四条相邻路线可走 |
| 第八章 · 时序观测庭 | `packages/core/src/level-data/temporal-observatory.ts` | 双时校准桥；零时摄政方向因双锚未校准受阻 |
| 第十九章 · 天幕监察城 | `packages/core/src/level-data/panopticon-city.ts` | 南部盲区中继；万目监察者方向因中继与潜入路线条件受阻 |

状态和可移动性来自 `packages/presentation/src/view-model.ts` 的 `getPhysicalAdjacentIds` / `getMapNodeState` / `buildMap`，经真实 `buildGameViewModel` 导出到 `fixtures.json`：

- 优先级：`current > cleared > adjacent > scouted > fogged`。
- `cleared` 也可能是当前相邻且可走，UI 必须读取 `isAdjacent` / `canMove`，不能仅判断 `state === adjacent`。
- fogged 没有 `nodeId`，title 为 `未知区域`，nodeType 为 `unknown`。原型不从原始内容回填隐藏信息。
- 普通物理连接由坐标曼哈顿距离 1 得到。**只对当前区域出发的边**显示可达/受阻；远端连线仅代表物理相邻，不宣称双向通行。章规门禁可能有方向性。
- 炼狱地图不是本原型范围。未来接入必须从 `infernoMap.connectionIds` 获取真实连接，不能用普通网格推边。

生成器从现有包产物读取生产 projection，不需要浏览器依赖：

```sh
node prototype/dungeon-map/generate-fixtures.mjs
```

从 `infinite-flow-wechat` 根执行。生成器仅覆写本目录的 `fixtures.json` 和对应的浏览器脚本 `fixtures.js`，两者来自同一份序列化数据；不构建、不修改源代码、不写存档。若包源码变更，需由正常项目构建更新产物后再生成；本次已比对三个章节的当前 `.ts` 定义与 `dist` 完全一致。

## 视觉与尺寸

- 颜色：墨绿底 `#101a19`、石质浮层 `#22342e`、旧金 `#d9bc7f`、正文 `#efe8d9`。
- 关键文字对比度已计算：正文 14.54:1、辅助文字 9.16:1、金色操作文字 5.61:1、受阻文字 6.65:1、未知点文字 5.58:1。
- 正文/辅助状态均通过文字或符号表达，不依赖颜色。禁止和可达分别有锁、文案及连线形态。
- 交互目标至少 44×44 px；近邻路线常规 69–72 px、短屏 56 px；底部按钮常规 46 px、短屏 44 px。
- 页面布局覆盖 320 / 390 px；320×568 短屏通过紧凑页头与64px当前位置卡片，让四条56px近邻路线同时可见。详细内容仅在面板内部纵向滚动，放大图的双轴滚动限制在图内。
- 底部“返回探索”固定，当前地图信息不会撑出屏幕宽度。
- 背景复用仓库 `art-source/dungeon-world` 的既有图；本次没有生成或新增 bitmap 资源、字体或第三方依赖。
