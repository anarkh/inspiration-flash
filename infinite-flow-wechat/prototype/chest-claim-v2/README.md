# 宝箱领取 v2 · 小弹窗原型

本轮重新设计宝箱领取与回响选择，缩小弹窗和图片，让场景保持可见。此目录是独立可点击演示，尚未应用到 Cocos 游戏。[打开本地原型](http://127.0.0.1:8125/prototype/chest-claim-v2/index.html)。

## 设计

- 弹窗最大宽度 304px，随场景收窄；320px 场景中实测宽 278px，两侧各留 21px，其中包含场景自身的 1px 边框。
- 回响候选纵向排列，每行高 66px：左侧 48×48px 图片完整等比显示，右侧 14px 名称、12px 效果说明。
- 待领取状态用标题旁的 48×48px 小宝箱；紧凑奖励行中的物资图框为 28×32px。弹框中的宝箱、物资和回响图片均使用 `contain`，不拉伸或裁切。
- 每个状态保留一个主要操作按钮，靠弹窗右侧：可见尺寸为 148×32px，文字 13px，点击区域高 44px；点选回响与确认获得分开。按钮上下各有 6px 的透明点击区域，保持小按钮视觉与触控可用性。

## 操作

默认打开「回响选择」，便于直接比较新尺寸和布局。页面外控件可切换「回响选择」「宝箱领取」、从头体验，以及 320 / 390 宽度；这些控件只供演示。

完整流程为：查看奖励 → 领取 → 同窗选择回响 → 确认获得 → 返回场景。点候选行仅切换选中项；关闭再打开保留当前选择，不跳过待处理回响。领取处理中禁止重复提交，完成后不能重复领取。无回响的普通物资领取后直接返回场景。

## 边界

所有交互只改变本页内存状态，不读取或修改用户游戏及存档，不调用游戏命令；旧原型和 Cocos 文件保持原样。固定两个回响候选仅用于布局示例，不代表用户当前候选；真实游戏仍可能出现 1–3 个候选。原有加成、探索补给和离场结算规则不在本轮原型中重新实现，领取不代表永久结算。
