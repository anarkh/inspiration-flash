# 主神空间 NPC 对话原型

供交互确认的独立 HTML 演示。暂不接入 Cocos 游戏界面。

## 打开

可以直接用浏览器打开本目录 `index.html`，或在 `infinite-flow-wechat` 根目录运行：

```sh
python3 -m http.server 8125 --bind 127.0.0.1
```

然后访问 <http://127.0.0.1:8125/prototype/npc-dialogue/index.html>。

## 交互

- 七位 NPC 都直接展示可滚动的完整列表，不显示搜索栏、类别筛选和当前资源栏，没有上一项 / 下一项。
- 点击条目图标或名称打开说明详情，不重复展示操作区；关闭后保留列表位置。支持 Escape 和点击遮罩关闭。
- 购买、培养、强化等操作直接跟在条目后面；装备的额外强化与封存在该条目的「更多操作」中展开。
- 商店不提供装备、携行、激活、出战、设为常用及装配记忆等购入后的配置操作，由玩家购入后在相应界面使用。
- 灰色操作可以点击查看该操作的条件；需确认的操作仅显示当前确认项。成功操作会更新演示库存与养成状态。
- 封存材料采用直接选择，不需要循环切换。恢复生命和装备封存委托位于对应 NPC 底部服务入口。
- 任务优先显示可领取和进行中的条目，已领取任务保留在列表末尾。

| NPC | 目录 | 条目数量 |
| --- | --- | ---: |
| 军需官 | 装备与强化 | 65 |
| 补给商 | 物资兑换 | 9 |
| 灵宠师 | 灵宠与培养 | 6 |
| 修行导师 | 功法与战技 | 7 |
| 血脉祭司 | 血统与觉醒 | 4 |
| 同行引路人 | 同伴与训练 | 3 |
| 任务使者 | 任务与奖励 | 63 |

顶部可切换「整备中的角色」与「初入空间」，并重置演示。在桌面可以切换 390 / 320 宽度；真实手机尺寸下自动适配。

## 数据与构建

`adapter.ts` 读取现有 core / presentation 目录，通过 application reducer 在内存中执行操作。`prepared` 是有资源、养成进度和可领奖任务的合成样本；`new` 使用游戏初始状态。均不读取或写入玩家存档、localStorage、微信存储，也不连接后端。刷新或重置即可还原。

`game-adapter.js` 是已构建的独立脚本；源码数据变化后，在项目根目录运行：

```sh
node prototype/npc-dialogue/build-adapter.mjs
```

图标和立绘复用 Cocos 资源；没有现成图标的条目使用文字占位。此原型用于确认列表与弹窗交互，不代表游戏已完成接入，也不包含在副本内推进封存委托的流程。
