P1

副本交互物仍是平涂几何图形

宝箱、陷阱、事件牌、勘探、遗物、共鸣祭坛、法则书台及副本 portal / exit，仍以矩形、三角和椭圆拼成，缺少与场景一致的材质、光照。

优先补齐宝箱和出口的独立素材，再覆盖六种事件物件；保留交互脚点。

正式渲染分支已确认；本轮未逐一进入每类房间截图。新万象画门、房间切换石门及其加载替身不计入。

P2

少数人物肖像的质感与场景立绘有差异

主角头像更偏暗色战术肖像；三位同伴及血脉祭司、同行引路人的肖像更偏摄影式人物头像。多数旧 NPC 的衣装能与新立绘对应，不建议整批重做。

先统一主角在面板与场景里的形象，再协调少数肖像的皮肤质感、景深、背景与画法；保留无限流角色的现代服饰设定。

原图目检 + 头像、人物面板、同伴目录和商店映射确认。此项为视觉统一建议，严重程度低于几何物件和旧横幅。

P2 · 绘制规范

主城与副本 HUD、摇杆有两套样式

主城是蓝灰半透明框和青色透明摇杆，副本是暖黑切角框和金色实心摇杆，同一控件跨场景的颜色和体量变化较大。

统一色板、刻线、透明度；菜单、地图和提示图标可继续使用矢量，不必全部换成图片。

当前庭院、战斗截图和正常绘制分支均确认。

建议保留与排除项

当前庭院、柱箱祭台灯、万象画门、房间切换石门、19 张副本世界背景、59 张怪物世界立绘、6 张灵宠及多数装备和材料，整体画法相容，不建议批量重做。相位猎杀无人机的青色能量较强，可结合科幻章节继续观察，暂不列为必须替换。

旧主神大厅背景、无正常商店映射的 forge_smith、旧详情模式中的怪物肖像、未选的九款传送门、仅加载或失败时出现的程序替身，均不按当前正常游戏画面的缺陷处理。

推荐顺序

副本宝箱、出口、碎石与事件物件 → 镜像城横幅和装备残片 → 功法血统图标 → 少数肖像与 HUD。
