# 全弹框紧凑原型 v1

把宝箱领取 v2 的暗金细框、小图横行和紧凑操作区推广到当前游戏的弹框，同时把领取按钮缩小。本目录提供可点击的本地设计原型，覆盖正式 UI 的 11 类 `MobilePanelKind`，以及其详情、确认、提示和运行状态浮层。

当前共 **133 个界面与状态样例**。这个数量包含同一弹框的内容页和状态变体，并不代表游戏有 133 种原生弹框。逐项来源与状态见 [COVERAGE.md](./COVERAGE.md)。

## 打开与导航

使用现有本地服务打开：[全弹框原型](http://127.0.0.1:8125/prototype/modal-system-v1/index.html)。如果服务尚未启动，可从 `infinite-flow-wechat/` 运行：

```sh
python3 -m http.server 8125 --bind 127.0.0.1
```

页面右侧按八组提供分类目录，完整下拉列表可以直接打开任何样例；底部“上一个 / 下一个”遍历全部样例。顶部可切换 390 × 844 与 320 × 568 的预览尺寸。

每个样例有独立 hash 路由，例如 [回响二选一](./index.html#relic-choice)、[角色信息](./index.html#player-character)、[章节列表](./index.html#entry-root) 和 [归档与回城](./index.html#result-archive)。点击条目可查看嵌套详情；关闭嵌套详情返回上层，收起最外层后点击场景内“打开弹框”再次显示。支持 Escape 关闭可收起的弹框。

## 统一样式

| 元素 | 规格与行为 |
| --- | --- |
| 窗体 | 最大宽 304px；320px 舞台内约 278px。高度随内容变化，受舞台可用高度限制，避免所有内容都撑满屏幕。 |
| 色彩与框线 | 深棕底、暗金细边、轻微角饰；标题和关键数值用浅金，正文保持清楚的阅读对比。 |
| 图片 | 标题 / 普通横行约 40px，奖励候选 48px；物品格约 32–36px。角色纸娃娃布局的装备槽图标为 28px，触控高度仍为 44px；角色立绘单独保留必要空间。 |
| 主按钮 | 可视面最大 148 × 32px；触控高度 44px。按钮可小于窗宽，默认靠右，与次操作并列。 |
| 内容区 | 长目录、属性、规则与结算在窗内滚动。标题、页签、短提示和底部操作保留在固定区域。 |
| 选择 | 初始无选中项；点击候选后显示选中标记，依赖选择的确认按钮才启用。 |
| 状态 | 区分可用、禁用、处理中、已完成、空列表和锁定；禁用时显示实际原因。 |
| 文案 | 游戏弹框使用短提示 `hint`；设计说明 `note` 显示在右侧说明区，不进入游戏操作内容。 |

## 保留的玩法契约

- 装备领取后永久拥有并收入背包，需手动穿戴；探索中可换装，战斗中禁换，换下的装备仍保留。
- 携行配置在主神空间调整；副本内只读。补给品不占携行槽，特殊道具按种类占槽，槽满时不能再装入。
- 装备、回响、入场协议、契约和归档候选初始不预选。锁定章节不能入场，解锁条件保留。
- 战斗法术与药品点击后直接给出使用反馈；风险行动与撤退保留确认过程。
- 本局回响获得后生效，仅本局有效。结算中的归档选择完成或明确跳过后才进入可回城状态；另有已遗失、无回响状态。
- NPC 兑换、学习、觉醒、培养与玩家自己的装备 / 养成配置分开。任务完成与任务奖励领取是不同状态。

所有数值、物品名与条件均以当前源码提供的真实样例为依据；固定样例并非某个玩家当前存档的回放。原型仅在当前页面内存中保存候选选择和导航状态，演示操作只切换原型页面或显示反馈，不读取游戏存档，也不发送游戏命令。刷新页面后重新开始演示。

本次没有增加抽卡或其他玩法。旧章册、旧结果场景和调试 gallery 的排除理由见覆盖文档。

## 文件与验证边界

- [index.html](./index.html)、[style.css](./style.css)：预览舞台与统一视觉规则。
- [app.js](./app.js)：公共渲染、路由、选中态和演示反馈；启动时检查重复 route 与缺失 target。
- [data-player.js](./data-player.js)：角色、行囊、地图、任务、记录、帮助与 HUD 提示。
- [data-hub.js](./data-hub.js)：NPC 目录、详情、服务、玩家配置与轮回入场。
- [data-interaction.js](./data-interaction.js)：探索行动、奖励、战斗菜单与完整结算分区。
- [data-system.js](./data-system.js)：场景加载、错误、初始化与阻断浮层。
