# 角色信息 · 携行原型

独立 HTML/CSS/JS 原型，仅使用示例库存，不连接游戏运行时、不读取或写入存档。
从 `infinite-flow-wechat/` 启动静态服务，再打开 `/prototype/carry-loadout/`；
也可直接打开 `index.html`（图标使用仓库内相对路径）。无新增依赖。

## 本次提案

- 将角色信息中的「整备」标签改为「携行」，上方固定展示 3 个通用携行槽，下方展示实际 6 种特殊道具。
- 点击有库存的道具即装入第一个空槽；同种不能重复携行，不减少库存，也不立即使用道具。
- 再次点击下方同一道具即可卸下，也可点击上方已装入的道具卸下，其他槽保持原位置。
- 未持有的道具灰色且禁用；已装备的道具标记「已装备 · 卸下」并保持可点击。满槽时其余道具置灰，先卸下再换装，不自动替换。
- 列表在小屏独立滚动，槽位与说明持续可见；支持键盘、焦点提示、状态播报及减少动效设置。
- 顶部演示设置可切换常规、空槽、满槽和全部未持有。默认库存是演示数据，不代表新档。
- 图标复用 `cocos/assets/resources/item/`；止血丹、护甲补片、定神香不在携行列表。

## 游戏接入

游戏已将「整备」标签替换为「携行」，原有装备穿戴、灵宠和同伴出战、功法/血统激活、
装备记忆激活从「角色 → 装备与养成」进入；行囊不再保留携行分页。
本原型里的「角色」仅是辅助导航示意，不实现以上配置能力。

实际规则是 3 个通用槽加装备附加的专用/任意挂载槽。此原型使用没有附加槽的装备情景；
游戏根据核心规则投影全部槽位，遵守类别优先匹配。

领域仍允许库存 0 时预配置；新界面按用户要求将未持有的道具置灰禁装，兼容存档中已装备的
零库存道具仍可卸下。携行仅在主神空间配置，入场记录快照，副本内页面只读。
已删除卸下时的「库存不变」提示与页脚中的库存说明。

## 权威源码

- `cocos/assets/scripts/ui/InfiniteFlowInfoSheet.ts`：现有角色整备、行囊携行入口。
- `packages/presentation/src/hub-shop.ts`：已拥有配置动作与 NPC 兑换/养成的边界。
- `packages/core/src/tactical-loadout.ts`：6 种特殊道具、3 个通用槽、去重和携行快照。
- `packages/core/src/equipment-field-rigs.ts`：装备附加槽。
- `packages/core/src/game.ts`：道具用途和实际使用条件。
