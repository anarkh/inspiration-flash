# 回响随身 / HUD 图标原型 V1

独立 HTML 交互原型。仅包含界面与静态示例，不读写真实游戏状态，也不修改生产代码。

## 查看

从 `infinite-flow-wechat` 启动任意静态服务器，访问 `prototype/hud-buff-icons-v1/`。默认是 390px 画面；顶部切换 320/390。`?detail=owned` 可直接展示本局回响列表；`?detail=mist_edge` 仍可展示图鉴中的雾锋单项详情，其他有效 relic id 同样支持。

- 顶部血条下回响区域是一个整体按钮：点击任一图标或图标间隙，打开本局全部已获得回响列表；再次点击整块区域收起。
- 本局列表只展示三项图标、名称、精确效果与关闭按钮，当前示例为雾锋、聚念棱镜、猎时钟三枚强攻回响；不再显示上方标题 / 项数或下方生效说明。
- 右側九枚图鉴：查看任意设计详情，不加入本局已获得列表。
- 关闭按钮、Esc、点浮层外都可收起。关闭按钮 / Esc 将焦点还给触发项。
- 奖励点与灵蕴按钮仅解释当前余额；不创建额外的商店、兑换或装备功能。
- 背包、菜单、地图、目标保留位置，点击仅在游戏画面外提示当前原型范围。
- “查看未获得状态”展示真实空状态：没有回响时隐藏图标行，不画未获得的空槽。

## 设计规格

| 项目 | 规格 |
| --- | --- |
| 游戏画面 | 390×780 CSS px，支持真实 320px 宽度，所有互动目标不随画面缩小 |
| 顶栏 | 角色左侧；名称 → 奖励点 → 灵蕴同排；下一行仅放生命数值，再下是短血条与回响；右上保留 2×2 背包 / 菜单 / 地图 / 目标 |
| 资源 | 古金金币 / 青玉符号 + 当前数字；aria-label 含中文资源名与完整余额 |
| 血条 | 3px 高灰绿色细条，与生命数值左对齐；本轮长度增加 20%，最大宽度 115.2px，窄屏随生命数值可用区收缩（320px 画面为 75.6px，390px 画面为 115.2px） |
| 回响 | 18×18px 专属彩图，可见水平间距 6px，首枚左沿与血条对齐；三枚图标共用一个 72×44px 整体按钮，每个 24×44px `.buff-slot` 仅作展示，无单图点击或嵌套按钮；视觉底部靠近头像框下沿 |
| 图鉴 | 54px 图标（手机外围图鉴 64px），每流派三枚，共九枚 |
| 浮层 | 264px 宽，位于回响下方，距画面左右至少 12px；本局列表箭头对准整块回响区域中点，图鉴单项详情仍借第一枚展示位中点定位 |
| 本局列表 | 视觉只保留三项列表与关闭按钮；每项为 30px 图标、名称和完整 description；隐藏“本局回响 / 已获得 · 3 项 / 自动生效 · 仅本局有效”等头尾说明及顶部单项大图；DOM 标题保留用于对话框的无障碍命名 |
| 图鉴单项详情 | 46px 专属图标、流派 / 类别、名称、精确数值、自动生效 / 仅本局；不改变本局持有列表；无装备按钮、倒计时或虚构稀有度 |
| 颜色 | 深青黑 `#111613`、古金 `#c6ac74`、象牙白 `#ede7d7`、灰绿生命 `#b3bf90` |
| 字体 | 标题用系统宋体；数值 / HUD 使用系统中文无衬线；正效果数字使用 Georgia |
| 触控与键盘 | 回响整体点击区为 72×44px，包含图标间隙；游戏入口、资源与关闭目标仍至少 44×44px；支持 Tab、Enter、Space、Esc；可见焦点；整块回响在 Tab 顺序中只有一个入口 |

320px 宽下去掉“生命”二字，仅显示 102/102，资源名称保留在 aria-label 与点击说明里。资源按钮原有内容与可访问名称保持不变，容器位于 `.name-line`。回响图标的屏内纵向设计目标为 y=62–80px，头像框为 y=13–74px，即视觉下沿仅超出头像框约 6px；此位置在过去布局中已测量，本轮整块按钮改造后由主任务复验。

回响行最多显示当前流派的三枚（core 当前规则不允许一局混合三种流派），因此不添加滚动、折叠或 “+N” 假需求。没有已获得回响时整个 HUD 按钮隐藏；图鉴仍可预览单项，浮层此时借短血条定位。当前样式引用为 `style.css?v=6`，脚本维持 `app.js?v=5`，便于刷新本轮布局。

## 图像与空状态

九枚专属图标已生成并接入 `assets/<id>.png`，实际资源均为 1254×1254 PNG。采用不透明近黑底、古铜 / 玉石 / 金属材质，图内不含文字；外侧古金细边由原型 CSS 统一绘制。

- `generation-prompts.json`：记录 `image_gen.imagegen` 的完整逐图 prompt、源图路径、输出相对路径与不透明背景设置。Prompt 的请求尺寸是 1024×1024，最终尺寸以实际文件及 manifest 为准。
- `assets/manifest.json`：记录九枚图标的 ID、相对于本原型目录的资源路径、实际尺寸、字节数及 SHA-256；状态为 `prototype-only`，尚未接入游戏资源清单。
- `assets/mist_edge.png` 等九张 PNG：供 HUD、图鉴及详情浮层共用，不裁切混用其他遗物图像。

规则来源：`packages/core/src/run-relics.ts`。不修改任何规则。初始例为强攻流派已获得全部三枚，HP 102/102、奖励点 1155、灵蕴 1。

加载期间图像透明，不用自绘符号冒充最终图标。图像加载失败时保留触控热区及可读详情，图鉴名称仍可见；生产落地时应补一个已有中性缺图标记与资源加载错误上报，不应静默使用其他遗物图像。原型不增加永久占位图，以免和最终图标设计混淆。没有回响时 HUD 整行隐藏；外围按钮可反复切换此状态。

实际场景与角色来自现有 `cocos/assets/resources`：妖塔一层、断符石盘、雾中妖鬼、轮回者头像及行走图集。

## 浏览器验收项

1. 320 / 390 下，名称与两种资源在同一行、不与右上入口重叠；生命数值位于下一行，下方为血条与回响。HUD 图标为 18×18px，可见水平间距 6px，首枚左沿与血条对齐；整块回响点击区为 72×44px，其他资源、入口及关闭按钮保持 44×44px；血条加长 20% 后分别为 75.6px / 115.2px，高度仍为 3px，与生命数值左对齐；回响视觉下沿靠近头像框下沿。
2. 点击任一 HUD 图标或两图间隙，都应打开同一本局回响列表，只展示三项图标、正确名称、完整 description 与关闭按钮；上方标题 / 项数和下方生效说明视觉隐藏，DOM 对话框命名保留。HUD 内没有单图交互或嵌套按钮。空状态整块按钮隐藏，没有图标或空槽。
3. 再次点击整块区域、点击关闭、Esc、点外部均可关闭；九枚图鉴仍可查看各自单项详情，不得改变本局持有列表。列表、单项详情、资源说明之间切换后不残留上种模式的样式或内容。
4. 逐个检查九张 PNG 加载成功，尤其雾锋 18px HUD 缩略图可辨识；列表行图标为 30px，图鉴 54/64px 与单项详情 46px 尺寸保持不变。
5. 页面无横向溢出，原游戏存档和原有预览页面不受影响。
