# NPC 商品网格原型

从项目根目录运行 `python3 -m http.server 8125 --bind 127.0.0.1`，打开：

<http://127.0.0.1:8125/prototype/npc-grid/index.html#equipment>

- 六位商品 NPC 使用纯图标网格，格子不显示名称、描述、价格或操作按钮。任务使者使用文字列表，显示任务名称、说明、进度与领取按钮。
- 图标及详情图标按品质显示边框：粗糙灰、普通白、优秀绿、精良蓝、史诗紫、传说橙。选中、悬停时保持品质色；详情同步显示文字品质，避免仅靠颜色辨别。
- 装备与道具复用 Cocos 背包已有的 UI 品质映射，与随机装备词条品质无关。功法、灵宠、血统和同伴尚无领域稀有度字段；已确认的示例配色作为游戏显示层分级沿用，不改变数值、掉落概率或存档。HTML 详情仍标注「原型示例」。
- 点击图标打开详情；名称、状态、效果、要求和数量均在详情查看。
- 兑换、升级等操作统一位于详情弹窗右下角，详情滚动时操作区保持可见。超过两个操作时由右下角「更多操作」展开。任务保留行内领取，也可在任务详情中领取。
- 条件不足的操作可以点击查看原因；高风险操作在同一弹窗说明消耗并确认。
- 支持 Escape、遮罩关闭、键盘焦点恢复；关闭详情保留网格滚动位置和选中边框。
- 恢复生命和装备封存委托从 NPC 面板右下角进入，使用相同详情和操作布局。
- 顶部可切换演示角色、320/390 手机宽度并重置状态。

复用 `../npc-dialogue/game-adapter.js` 的完整商品和内存 reducer，适配器新增只读 `rarity` 显示字段；原型本身不会读取或写入玩家存档。已确认的网格、任务列表与详情操作布局现已应用到 Cocos 游戏；游戏复用正式 ViewModel 与命令。装备、补给和灵宠图像直接复用现有游戏资源。功法、血统、同伴已配独立位图，并补齐血脉祭司与同行引路人头像；图像与完整生成提示词见 [assets/README.md](assets/README.md)。

旧版列表原型保留在 `../npc-dialogue/index.html`，可对照查看。
