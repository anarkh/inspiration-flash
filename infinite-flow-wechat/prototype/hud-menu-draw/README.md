按用户反馈重做全部十款：入口只显示图标，角色与生命区域取消底板。
当前十款均采用透明顶部与透明角色入口，没有石板、纸卷、玉板、大圆章或整条深色背景。
本次紧凑调整隐藏顶部区域名（如「妖塔一层」）和试玩提示（如「临时试玩」），
将菜单、背包、地图、目标合为右侧连续紧凑的四入口列，缩小入口间距，保留透明点击区域。
本次纯图标调整隐藏角色及右侧四入口的可见名称，五个入口图标统一放大到40逻辑像素，
09 也显示图标；透明紧凑布局继续保留，右侧入口实际触摸高度维持约44px。
「看现用」仍展示原有布局，供对照。

本目录是独立HTML原型，未修改正式Cocos界面、游戏规则、资源注册或存档。
场景只读引用现有游戏素材并作静态组合，不代表引擎试玩。

## 打开与操作

地址：http://127.0.0.1:8125/prototype/hud-menu-draw/ （使用现有项目静态服务）

- 抽一张：先抽未看过的牌，全部看过后开启新轮。
- 留这张：收藏至本浏览器。第二轮使用独立收藏记录，不覆盖旧版留牌。
- 钉住对比：固定一款再抽另一款；宽屏并排、手机纵向比较。
- 展开十款：总览、直接选卡、只看留牌。
- 看现用：现有正式界面的HTML近似复现，不是Cocos截图。
- 环境和生命状态：三种背景、满血/受伤，同步作用于比较双方。
- 角色、菜单、背包、地图、目标：打开共享示例面板，Esc或关闭按钮返回原入口。
  这些面板仅验证点击；本轮设计范围仍是截图红框内的HUD和菜单入口。
- URL的#01至#10可直达。可以选整套，也可以组合不同方案的顶栏与侧边入口。
