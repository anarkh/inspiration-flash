# 妖塔选路与追兵 HTML 原型 v1

验证副本「每个格子一个事件」之外的两点改动，能完整打一局妖塔一层：

- **方案一：追兵和压力出现在场景里**（只改界面）。监猎者在小地图上是红点；它在
  哪个方向，那扇门就渗红光，只隔一间时门口出现剪影。顶部压力条随清理房间数
  推进，换档时全屏提示。小地图用虚线圈标出封印点「雾后暗格」。
- **方案二：选门就是选路**（小改规则）。门上显示下一间的类型、危险度和奖励加成，
  没进过的房间不显示名字。灯油每走一步耗 1，补给房 +4；烧完后压力直接进入破界，
  监猎者立即苏醒。

本版只新增独立 HTML 原型，没有改正式 Cocos 游戏、领域包或任何进度。

打开：`http://<开发机 IP>:8125/prototype/dungeon-route-v1/index.html`
（从 `infinite-flow-wechat/` 起静态服务）。

## 规则来源

| 内容 | 来源 |
| --- | --- |
| 30 个房间的位置、类型、标题、描述、陷阱与奖励数值 | `packages/core/src/level-data/demon-tower.ts`，复制到 `data.js` |
| 压力：清 6 间追猎（怪物 +10%，奖励加成 +5%），清 12 间破界（+20%，无加成），稳定期 +15% | `run-pressure.ts` |
| 监猎者：清 6 间后在「剔骨巡卒」苏醒，每走一步沿最短路追一步；撞上扣 15% 生命 +1 并退回巢穴、下一步不动；先清空「雾后暗格」再引过去可封印，成功撤离带回妖骨；没处理会在进首领房时融合，首领 +15% | `run-pursuit.ts`、`game.ts` |
| 首领与出口：骨巷塔卒为首领（生命 ×1.25），击败前白光裂口封印 | `boss-system.ts`、`game.ts` |
| 战斗胜利后回满生命 | 小游戏既有规则 |

示意规则（只为原型简化，不代表正式数值）：灯油 12 / 补给 +4 / 被撞额外 -2 灯油；
战斗按「普攻对拼」自动结算，雷火符开场 48 伤害、止血丹不够血时自动服用；陷阱
硬闯按「d6 + 陷阱检定 5 ≥ 难度」；玩家走进监猎者所在房间也算被撞；传送门不开放，
只当通路；中途撤离保留已获得物品、失去出口奖励，失败只带回 30% 轮回点。

## 操作

点门（或方向键 / WASD）走到隔壁房间，进门后自动弹出房间事件。事件面板可「收起」
先看门，用右下「处理」或点房间中央物件重新打开；没处理完不能离开，但怪物、首领
和陷阱可以「退回上一间」。左下「撤离」随时中途离开。桌面右侧可切换 390×844 /
320×568、重新开始。
