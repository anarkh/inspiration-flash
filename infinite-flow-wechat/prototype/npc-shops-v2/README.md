# 商人专属列表原型 v2

替代 `../npc-grid/` 的纯图标网格：每位商人按商品特点使用自己的布局，列表直接显示名称、状态、效果和价格，并说明买来的东西在哪里生效。

从 `infinite-flow-wechat` 根目录启动静态服务后打开：

```sh
node prototype/npc-shops-v2/build-adapter.mjs   # 用当前游戏源码重建演示数据
python3 -m http.server 8762 --bind 127.0.0.1
```

<http://127.0.0.1:8762/prototype/npc-shops-v2/index.html#supplies>（`?w=320` 切到小屏）

| 商人 | 布局 | 每条显示 |
| --- | --- | --- |
| 补给商 | 分「补给品 / 携行道具」两段的行列表，行内兑换 | 图标、名称、携行状态、持有数、效果、单价 |
| 军需官 | 七个部位页签 + 行列表，已装备、已拥有排在前面 | 名称、已装备 / 等级 / 可兑换 / 未解锁、基础属性、升级或兑换消耗 |
| 修行导师 | 行列表，已学排在前面 | 阶位、常用、被动、战技、学习或精研消耗 |
| 灵宠师、血脉祭司 | 两列角色卡 | 立绘、出战或激活标记、阶位、加成、爆发、主操作（签约 / 觉醒 / 培养 / 晋升） |
| 同行引路人 | 单列宽卡 | 立绘、定位、援护技能、招募条件或消耗、主操作 |

- 点击条目打开详情：顶部「在哪里用」写明生效方式（如战斗「法术 → 同伴」），下方列出全部属性，底部是全部可执行操作。
- 商人只负责购买和升级；灵宠、同伴、血统的出战与功法常用在游戏角色面板的对应页签（灵宠 / 同伴 / 血统 / 功法）设置，卡片和详情会写明这一点。
- 窗口按游戏实际尺寸绘制：390 宽时 304×464，320 宽时 288×464。原型中的按钮是紧凑可视体；落到 Cocos 时仍按 104 设计像素透明热区包裹。
- 品质色沿用游戏网格已有的显示分级，不新增领域字段。数据和操作来自真实 ViewModel 与 reducer，只影响本页演示进度。
