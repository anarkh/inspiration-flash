# 战斗页面 HTML 原型

打开 `http://127.0.0.1:8125/prototype/combat/`。静态服务根目录为 `infinite-flow-wechat/`；
也可直接打开 `index.html`。无需安装依赖。

本目录是已确认的独立 HTML / CSS / JS 交互原型；布局、两步操作和动画已接入 Cocos。
原型仍保持隔离，不读取游戏状态，不写存档，不调用正式游戏命令。
原生实现位于 `cocos/assets/scripts/ui/InfiniteFlowCombatEffects.ts`、`InfiniteFlowWalkScene.ts`、
`InfiniteFlowInfoSheet.ts` 和 `InfiniteFlowView.ts`，结算使用游戏实际领域事件。

## 当前范围

- 沿用黑金风格、妖塔背景、我方状态、回合和敌人意图、右侧信息入口。
- 左下摇杆／WASD／方向键可移动主角，站位不改变战斗演示结算。
- 6 个战斗操作以 3 列 × 2 行全部同屏，不翻页；18px 图标、约 52px 等宽单格按钮，攻击和脱离战斗不再加宽，保留摇杆。
- 普通攻击与武器战技合为一个「攻击」按钮：战意 0–2 时点击普攻，达到 3 时自动切换为战技，释放后清空战意并切回普攻。当前模式与战意直接显示，战技就绪时高亮；无需弹窗或二次确认。
- 取消「进阶战术」入口；已解锁的归息、镇岳直接出现在法术列表，未配置的同伴／血统／魂技不展示空入口。
- 法术与药品为两步操作：点击入口，再点击所选法术／药品立即释放／使用，不进入详情或二次确认。
- 法术含基础术法、归息、镇岳；效果、回合消耗和不可用原因直接显示在选项上。
- 弹窗改为底部内容自适应小面板，最高 42dvh，不压暗或模糊战场；法术三卡横排。
- 止血丹也可从背包直接点击使用；满血／库存不足置灰并显示原因。关闭和 Escape 不消耗回合。
- 雷火符未携行时可查看原因；「携带雷火符」与「动作慢放」场景提供 1 张符用于动画演示。同伴／血统／魂技未配置。
- 一键防御保留；第 2、5、8…回合预告蓄力重击，显示「建议防御 · 承伤 30 → 8」并突出防御按钮。守势已生效时显示实际预计承伤，不重复推荐防御。
- 敌方按行动前的预告结算反击；普通追击为 12（防御后 6），重击为 30（防御后 8）。防御应对重击获得 2 点战意，普通攻击／术法／用药／常规防御获得 1 点，武器战技清空战意。
- 「放弃本轮并回收」移到菜单；脱离当前战斗和放弃整轮分别确认。胜利、濒死或撤退后可重新演示。
- 顶部演示器支持常规、重击预警、满血、缺药、功法已用、战意充足、低生命、携带雷火符、动作慢放，并可随时重置。重击预警从第 2 回合、1 点战意开始，便于对比防御与攻击的结果。

## 战斗动画

- 普攻：短促前踏、单道金色刀光、命中火星；战技：金色蓄力环与两道更重的交叉斩击。
- 术法：青色符纹聚气、飞弹轨迹、命中扩散环；归息使用青绿气流，镇岳使用金色护盾。
- 道具：止血丹浮起并吸收，绿色光点与生命环显现；雷火符以符纹引导金色落雷。
- 敌方反击：局部前压、红色爪痕和角色受击反馈；防御时改为护盾承受冲击。
- 伤害、治疗、道具数量在对应命中／吸收点更新；敌方反击随后结算，回合在动作完成后推进。普通完整行动约 1.1–1.4 秒，功法技约 0.6 秒。
- 六个小按钮、一键攻击、法术／药品两步释放保持不变；播放期间禁用重复行动与移动，完成后恢复。随时重置会取消未完成动作并清除粒子、位移和待处理结算。
- 顶部选择「动作慢放」以 2.5 倍时长查看动作细节；选择「战意充足」可以直接查看武器战技。
- 特效限制在战场内，状态栏与操作区位于特效上方；尊重减少动态效果偏好，改用短暂透明度变化并保留数值反馈。

生命、伤害、战意、反击数值为方便观察界面反馈的固定示例，不是第二套领域规则。
攻击按钮以带有战技的武器为示例：普攻 18、战技 32、雷火符 30。正式接入时，只有当前武器存在可用战技才自动切换，否则仍执行普攻。
止血丹演示基础回复 36；功法技各一次且不耗回合。正式接入时必须改用既有 ViewModel／dispatch，
以游戏领域层的伤害、使用条件、回合和结算为准。

## 文件与素材

- `index.html`：页面结构、战场敌人 SVG（依据现有 `drawMonster` 轮廓转写）。
- `style.css`：配色、布局、窄屏适配、状态样式和动效。
- `app.js`：隔离的示例状态、选项列表／详情、模拟行动与移动。
- `combat-effects.js` / `combat-effects.css`：局部特效和动作时间线，只通过命中回调通知原型结算，不自行修改战斗数据。
- 场景复用 `cocos/assets/resources/dungeon-world/demon_tower_1-v1.png`。
- 主角复用 `character/reincarnator-walk-v1.png` 的 4 × 4 透明动作表。
- 敌人插画仅在敌情详情展示；丹药动画复用 `item/healing-pill-v1.png`，不新增素材依赖。

使用语义按钮、原生 modal dialog（焦点限制与 Escape 关闭）、可见焦点、状态播报，
并尊重 `prefers-reduced-motion`。320px 窄屏保留完整操作区。
