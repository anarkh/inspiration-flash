## 验收目标

由 `npm run balance:sim` 的典型玩家机器人衡量，`npm run balance:report -- --check` 自动比对（区间定义在 `scripts/balance/targets.mjs`）：

| 项 | 目标 |
| --- | --- |
| 战力 / 推荐 | 每章 0.9–1.3 |
| 普通战 | 平均 2–4 回合，承伤 10–25% 最大生命 |
| 首领战 | 8–12 回合；按预告应对承伤 50–80%，乱打会吃药或失败 |
| 走向 | 普通战与首领承伤不比前两章平均低 5 个点以上；19 章一次通关 |
| 经济 | 通关后剩余奖励点 + 灵蕴（按 1500 折算）不超过两章收入 |

## 现状诊断（基线 0.1.25）

### 难度曲线

用典型玩家机器人从新档打到第 19 章：全部一次通关、零阵亡，但几乎所有目标都不达标（见文末基线表）。

| 阶段 | 战力 / 推荐 | 实际情况 |
| --- | --- | --- |
| 第 1 章 | 1.25 | 相对最难：普通战平均承伤 29%、最高 62%；首领 121%，要吃药 |
| 第 2–13 章 | 1.8–2.8 | 普通怪 1 回合死、几乎不掉血，首领承伤 ≤35% |
| 第 15–19 章 | 1.5 → 1.26 | 首领 100–200% |

设计者的跳章存档（`chapter-trial.ts`，战力是推荐值的 1.09–1.24 倍）在第 15–19 章的首领战里承伤 280–445%、用药 4–8 颗。

### 战斗公式（`game.ts` 约 8504–8516、9875 行）

- **普攻**：`max(3, 攻击 − ⌊0.6 × 防御⌋)`。
- **术法**：`max(5, 术强 + 8 − ⌊0.3 × 防御⌋)`。
- **怪物反击**：`max(3, 攻击 − ⌊0.6 × 玩家防御⌋)`。

由此带来的问题：

- **减法防御的断崖**：第 9 章前玩家防御几乎吃掉全部怪物攻击，第 5 章首领只打 3 点。
- **百分比加成被放大**：困难、炼狱的百分比加成同时抬高怪物防御，物理伤害塌到下限，伤害增长快于百分比本身。
- **术法远强于普攻**：只扣 0.3 防御还 +8，1 点灵力 +4 术强，1 点体质只 +3 攻击。第 10 章起术法约是普攻的 2.1–2.4 倍。
- **首领是血包**：血量倍率从 1.25 涨到 2.4，第 19 章首领要普攻 23 次。
- **死属性**：怪物术强不参与伤害，速度只影响逃跑，幸运只影响逃跑和陷阱。
- **守势叠成免费动作**：多种减伤连乘再扣固定格挡，第 19 章防住重击只吃 0–1 点。

### 成长与战力

- **基础属性固定**：基础属性永远是 3/2/2/1。第 19 章约 70% 的战力来自装备。
- **装备有断档**：第 5、7 章没有新装备；手、脚、腰第 10 章后没有新装备。
- **附加项不随章节成长**：铭刻、淬火、套装、灵宠、遗物的数值固定，价格却每章 +15%。
- **战力是加权和**：
  - 公式是 `3×攻 + 2.4×术 + 0.25×生命 + 3×防 + 1.5×速 + 1.5×陷阱感知`；
  - 漏算了同伴、词条、灵宠支援、血统效果；
  - 推荐战力在 `progression.ts` 和每章数据里各写一份，已经不一致。
- **战力的机制用途不合理**：战力不足时结算奖励更多；炼狱词条重掷只保留战力更高的结果。

### 经济

- **货币积压**：第 9 章起奖励点和灵蕴大量积压，通关后剩 6.3 万奖励点、304 灵蕴。
- **材料过剩**：章节材料每局掉 25–40 个，只用得上 1 个。
- **限制战力上限的是解锁进度，不是钱**：省着打的「速通」机器人少赚约 40%，最终战力几乎一样。

### 顺带发现

第 7 章回声怪（`main_god_echo`）的意图永远推荐防御。照提示打会一直防到死，需要修正。

## 交付计划

1. **数值模拟工具（本 PR）**
   - `scripts/balance/`：典型玩家机器人、跳章存档对照、目标比对；
   - 记录本文与基线。
2. **装备与成长曲线**
   - 补齐第 5、7 章和手、脚、腰后期装备；
   - 附加项按章节档次成长；
   - 装备等级上限 5；
   - 定义每章的「标准玩家」属性曲线，作为后续怪物数值的基准。
3. **战斗公式与怪物曲线**
   - 防御改为比例减伤；
   - 怪物分物理 / 术法攻击，加入术抗；速度差换成固定减伤；
   - 按目标回合数和承伤，重配 19 章怪物与首领；
   - 修正第 7 章回声怪的意图。
4. **战力与推荐值**
   - 战力按实际战斗公式估算，计入同伴、词条等；
   - 推荐值从章节怪物推出，只保留一处；
   - 去掉「战力不足奖励更多」。
5. **经济与消耗**
   - 产出、价格和第 4/5 级强化对上曲线；
   - 幸运参与奖励加成。

每个 PR 附上模拟数据，重建本地预览供试玩。

## 工具用法

```bash
npm run build                               # 机器人读取 packages/*/dist
npm run balance:sim                         # 典型玩家 1→19 章，结果写 .balance/campaign.json（约 15 秒）
npm run balance:sim -- --mode rush --name rush   # 只打首领加顺路奖励的玩家
npm run balance:sim -- --pills 0 --name nopills  # 不囤药
npm run balance:report                      # 打印每章表格和目标比对；加 --check 时不达标返回 1
npm run balance:trial                       # 用每章的跳章存档各打一次
```

### 机器人的行为与局限

- **局内**：
  - 只走已发现、合法的格子，先拿奖励、再打怪、再处理陷阱；
  - 清完全图再打首领离场；
  - 有反制道具就用，否则硬吃陷阱；
  - 法则 / 事件选第一个非高风险选项，回响遗物选第一个，精英战利品拿战力增幅最大的。
- **战斗**：
  - 先用功法技；生命低于 35% 吃药；战技安全时用；
  - 危险预告时防御，但连续防御两次后强制出手；
  - 其余按预告推荐，默认取伤害预览更高的攻击或术法。
- **主神空间**：
  - 领任务、回血、补到 3 颗药；
  - 然后按「战力增幅 / 花费」贪心购买（1 灵蕴折 1500 奖励点）；
  - 新装备连同后续升级一起评估。
- **局限**：
  - 不用传送门、捕获、困难 / 炼狱、路线契约、装备追猎；
  - 只按属性评价购买，不看功法技、血统效果等非属性收益；
  - 战斗没有随机，换种子只影响 ±80 奖励点。
- **结果只代表一种合理打法**：机器人没有考虑的玩法（例如有意不清图），由跳章存档对照和试玩补充。
