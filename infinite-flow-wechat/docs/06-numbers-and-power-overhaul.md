| 项 | 决定 |
| --- | --- |
| 范围 | 战斗公式与怪物/首领曲线、装备与成长曲线、战力与推荐值、经济与消耗 |
| 战斗公式 | 防御改为比例减伤，术法与普攻统一口径 |

- 属性换算系数（`game.ts` 的 `getPermanentDerivedStats`：每点体质 +14 生命等）；
- 陷阱公式。

| 项 | 目标 |
| --- | --- |
| 战力 / 推荐 | 每章 0.9–1.3 |

| 经济 | 通关后剩余奖励点 + 灵蕴（按 1500 折算）不超过两章收入 |

## 现状诊断（基线 0.1.25）

### 难度曲线

用典型玩家机器人从新档打到第 19 章：全部一次通关、零阵亡，但几乎所有目标都不达标（见文末基线表）。

| 阶段 | 战力 / 推荐 | 实际情况 |
| --- | --- | --- |
| 第 1 章 | 1.25 | 相对最难：普通战平均承伤 29%、最高 62%；首领 121%，要吃药 |
| 第 2–13 章 | 1.8–2.8 | 普通怪 1 回合死、几乎不掉血，首领承伤 ≤35% |
| 第 15–19 章 | 1.5 → 1.26 | 首领 100–200% |

设计者的跳章存档（`chapter-trial.ts`，战力是推荐值的 1.09–1.24 倍）在第 15–19 章的首领战里承伤 280–445%、用药 4–8 颗。

### 战斗公式（`game.ts` 约 8504–8516、9875 行）

- **普攻**：`max(3, 攻击 − ⌊0.6 × 防御⌋)`。
- **术法**：`max(5, 术强 + 8 − ⌊0.3 × 防御⌋)`。
- **怪物反击**：`max(3, 攻击 − ⌊0.6 × 玩家防御⌋)`。

由此带来的问题：

- **减法防御的断崖**：第 9 章前玩家防御几乎吃掉全部怪物攻击，第 5 章首领只打 3 点。
- **百分比加成被放大**：困难、炼狱的百分比加成同时抬高怪物防御，物理伤害塌到下限，伤害增长快于百分比本身。
- **术法远强于普攻**：只扣 0.3 防御还 +8，1 点灵力 +4 术强，1 点体质只 +3 攻击。第 10 章起术法约是普攻的 2.1–2.4 倍。
- **首领是血包**：血量倍率从 1.25 涨到 2.4，第 19 章首领要普攻 23 次。
- **死属性**：怪物术强不参与伤害，速度只影响逃跑，幸运只影响逃跑和陷阱。
- **守势叠成免费动作**：多种减伤连乘再扣固定格挡，第 19 章防住重击只吃 0–1 点。

### 成长与战力

- **基础属性固定**：基础属性永远是 3/2/2/1。第 19 章约 70% 的战力来自装备。
- **装备有断档**：第 5、7 章没有新装备；手、脚、腰第 10 章后没有新装备。
- **附加项不随章节成长**：铭刻、淬火、套装、灵宠、遗物的数值固定，价格却每章 +15%。
- **战力是加权和**：
  - 公式是 `3×攻 + 2.4×术 + 0.25×生命 + 3×防 + 1.5×速 + 1.5×陷阱感知`；
  - 漏算了同伴、词条、灵宠支援、血统效果；
  - 推荐战力在 `progression.ts` 和每章数据里各写一份，已经不一致。
- **战力的机制用途不合理**：战力不足时结算奖励更多；炼狱词条重掷只保留战力更高的结果。

### 经济

- **货币积压**：第 9 章起奖励点和灵蕴大量积压，通关后剩 6.3 万奖励点、304 灵蕴。
- **材料过剩**：章节材料每局掉 25–40 个，只用得上 1 个。
- **限制战力上限的是解锁进度，不是钱**：省着打的「速通」机器人少赚约 40%，最终战力几乎一样。

### 顺带发现

第 7 章回声怪（`main_god_echo`）的意图永远推荐防御。照提示打会一直防到死，需要修正。

## 实施记录

### PR 2：装备与成长（0.1.27）

用户 2026-11-02 选择不加新装备（每件装备都有独立图片），只靠数值补曲线。

- **基础数值拉平**：
  - 每个部位以首次出现章节最早和最晚的装备为锚点，中间的装备按章节线性插值到目标强度。
  - 强度按战力权重折算：攻 3、术 2.4、生命 0.25、防 3、速 1.5、陷阱感知 1.5、体魄 18.5、心神 12.6、身法 4.5、气运 1.5。
  - 每件装备保留原有的属性构成，基础值和每级成长按同一比例缩放，取整后正值至少为 1。
  - 结果是第 3–12 章武器的平台期被拉开（例如第 12 章朱批刃攻击 20 → 28）。
  - 手、脚、腰只在本部位已有的章节区间内插值。
- **等级上限 3 → 5**：
  - 第 4、5 级照常加每级成长。
  - 费用：
    - 第 4 级：600 奖励点 + 2 灵蕴 + 3 个来源章节材料；
    - 第 5 级：900 奖励点 + 3 灵蕴 + 1 裂核 + 5 个来源章节材料。
  - 奖励点仍按来源章节每章 +15%；具体数额在 PR 5 再调。
- **3 级门槛**（`EQUIPMENT_MASTERY_LEVEL`）：
  - 铭刻、淬炼、同源共鸣、装备记忆、装备委托、勘探冻结来源，原来要求「最高等级」，现在固定为「达到 3 级」，即旧上限。
  - 存档校验同步放宽为「3 级及以上」，旧档不受影响。
- **附加项按来源章节放大 ×(1 + 0.15 ×（章 − 1）)**：
  - 范围：固定词缀、铭刻、淬炼、套装。
  - 倍率与价格的每章 +15% 一致，所以性价比不再逐章变差。
  - 取整后至少为 1；负值不变。
  - 套装加成按凑齐该档的那一件计算：两件套看第二新的件，三件专精看第三新的件。
  - 铭刻和套装的说明文字改为按实际数值生成，属性名统一为界面用语（心神、陷阱感知）。
- **跳章存档**：
  - 上一章的装备为 3 级，每早一章多 1 级，最高 5 级。

### PR 3：战斗公式与怪物曲线（0.1.28）

- **比例防御**（`packages/core/src/combat-math.ts`，取整后至少 1）：
  - 普攻：`攻击 × 100 / (100 + 防御)`；
  - 术法：`(术强 + 8) × 100 / (100 + 0.3 × 防御)`，与旧公式在低防御时的比值一致，术法仍要消耗战意、仍强于普攻；
  - 战技、同伴出手、破甲词条用同一套比例。
- **怪物分物理和术法**：
  - 每击 = 攻击按玩家防御减免 + 术强按玩家**术抗**减免；
  - 术抗 = 心神 × 3 + ⌊防御 / 2⌋，角色面板新增显示；
  - 房间战斗预告的敌人一栏加上术法。
- **速度差换减伤**：玩家每比怪物快 2 点，承伤 −1%，最多 −20%；慢于怪物不加伤。
- **第 7 章回声怪意图**：
  - 复制攻击或术强时，压迫伤害无法防御，预告改为「危险，不要防御，尽快击败」；
  - 复制防御或速度时，改为推荐术法、战技、雷火符，这些高额单次伤害更能穿透。
- **标准玩家曲线**（`scripts/balance/standard-player.mjs`）：
  - 第 1 章是新存档；第 2–19 章取跳章存档与 PR 2 机器人的中点，三章平滑后保持不降；
  - 后期装备到 5 级封顶，曲线变平，难度靠目标继续上升；
  - 怪物按这条曲线拟合；推荐值取跳章存档的战力（见 PR 4）。
- **怪物重配**（`npm run balance:fit`）：
  - 目标（对标准玩家，按其攻击和术法中较高的一击计）：

    | 类型 | 回合 | 每击占玩家生命 |
    | --- | --- | --- |
    | 普通怪 | 2.6 → 3.1 | 5.5% → 8% |
    | 精英（第 8 章起单独的精英怪） | 3.8 → 4.2 | 普通的 1.15 倍 |
    | 首领 | 8.5 → 10 | 封印期 1 倍、觉醒期 1.2 倍 |

  - 怪物速度取玩家的 0.6 倍，标准玩家总能闪掉一点伤害；
  - 保留：防御、普通怪在本章内的生命与攻势比例、攻击与术强的比例、所有怪物机制和效果伤害；
  - 首领倍率与两阶段的攻击加成一并重算；第 1–7 章的精英与首领同源，按首领调校；
  - 比例都对标准玩家计算（打几下死、每击伤害、物理占伤害的份额），所以重配已拟合的数值结果不变。
- **逐章校准**（`npm run balance:calibrate`）：
  - 公式不考虑侵蚀压力、章节法则和怪物机制，所以每章再乘四个系数（普通怪生命与每击、首领生命与每击）；
  - 系数由机器人和跳章存档的平均战况迭代得出，目标是普通战 3 回合、承伤 12% → 18%，首领 8.5 → 10 回合、承伤 50% → 65%；
  - 第 1 章只看机器人，因为玩家带的是新存档，第 1 章的跳章存档已有装备；
  - 普通怪生命系数不低于 0.7：第 1 章的剔骨塔卒有厚甲，精英战拖长时改为减轻每击，避免妖鬼一刀即死。
- **跳章存档补上铭刻**：
  - 3 级及以上的装备带战力最高的铭刻；
  - 以前缺这一项，跳章存档比同章的真实玩家弱一截（第 8 章生命 223 对 421）。
- **机器人只在防御是首选应对时才防御**：
  - 梦牢看守的「符丹封锁」是危险预告，但它只限制道具；
  - 之前机器人会整场防御，跳章存档因此在第 6 章失败。
- **验收**：
  - `AC-LAW-CORE-05` 的夹具角色只有体质 10、无装备，只普攻打不完四场竞技场战斗；
  - 判词期望与此无关；
  - 按规则新增 `AC-LAW-CORE-20`：同样的步骤与期望，体质 18；`AC-LAW-CORE-05` 显式废弃，`AC-LAW-05` 改指 `AC-LAW-CORE-20`。

### PR 4：战力与推荐值（0.1.29）

- **战力按实际战斗估算**（`packages/core/src/progression.ts`）：
  - 战力 = 4 × √（每回合伤害 × 有效生命）+ 1.5 × 陷阱感知；
  - 对一个参照敌人计算：防御 30，伤害一半物理、一半术法，速度为你的 60%（与拟合的怪物一致），一场 4 回合；
  - **每回合伤害**：按战意规则走 12 回合，战意满放武器战技，术法比普攻高且有战意时用术法，否则普攻；普通战与精英 / 首领战（每 3 回合防一次重击，防御给 2 点战意）各占一半；
  - 计入武器战技（直接调用 `resolveWeaponSkill`）、同伴出手与送战意、灵宠助攻、血统每击加伤，以及先手、斩杀、凝神、术法精通、战技精通、破甲词条；
  - **有效生命**：生命按防御与术抗各半折算，加速度闪避、同伴急救、血统护盾与吸血、灵宠灵障与预警、预判词条；
  - 旧公式（`3×攻 + 2.4×术 + 0.25×生命 + 3×防 + 1.5×速 + 1.5×陷阱感知`）不计同伴、灵宠、血统和武器战技；新存档仍约 180，后期数值更大。
- **推荐值只保留一处**：
  - 只读每章数据里的 `recommendedPower`；删去 `progression.ts` 里与之不一致的第二份表；
  - 由 `npm run balance:recommend` 生成：第 1 章取新存档的战力（向下取整，新存档显示为「已达到推荐」），之后各章取该章跳章存档的战力，不低于上一章；
  - 跳章存档就是 PR 3 校准怪物所用的装备水准，在这个战力下，该章战斗落在目标区间。
- **去掉「战力不足奖励更多」**：结算倍率和评分不再按战力是否达到推荐加成。
- **跳章存档按新战力配装**：
  - 每个部位的候选都带上淬炼与铭刻再比较；

npm run balance:fit                         # 按标准玩家曲线打印怪物与首领的新数值；加 -- --write 写回源码（之后重新 build）

### 机器人的行为与局限

- **局内**：
  - 只走已发现、合法的格子，先拿奖励、再打怪、再处理陷阱；
  - 清完全图再打首领离场；
  - 有反制道具就用，否则硬吃陷阱；
  - 法则 / 事件选第一个非高风险选项，回响遗物选第一个，精英战利品拿战力增幅最大的。
- **战斗**：
  - 先用功法技；生命低于 35% 吃药；战技安全时用；
  - 危险预告且首选应对是防御时才防御，连续防御两次后强制出手；
  - 其余按预告推荐，默认取伤害预览更高的攻击或术法。
- **主神空间**：
  - 领任务、回血、补到 3 颗药；
  - 然后按「战力增幅 / 花费」贪心购买（1 灵蕴折 1500 奖励点）；
  - 新装备连同后续升级一起评估。
- **局限**：
  - 不用传送门、捕获、困难 / 炼狱、路线契约、装备追猎；
  - 只按属性评价购买，不看功法技、血统效果等非属性收益；
  - 战斗没有随机，换种子只影响 ±80 奖励点。
- **结果只代表一种合理打法**：机器人没有考虑的玩法（例如有意不清图），由跳章存档对照和试玩补充。
