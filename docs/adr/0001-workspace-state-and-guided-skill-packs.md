# Use workspace-local state and guided skill packs

The first Personal Agent stores Project Memory, Task Runs, Checkpoints, and workspace-specific configuration as Workspace State in the active workspace, and uses Skill Packs as guidance and supporting resources rather than as a plugin runtime. This keeps the first version transparent, local, and easy to inspect while preserving a future path to a stronger ability runtime; the trade-off is that cross-workspace memory, cloud sync, and fully autonomous plugin execution are intentionally out of scope for the first version.
