# Personal Agent Knowledge Base / Personal Agent 知识库

The Knowledge Base explains how the Personal Agent is built while the Owner learns agent concepts by using it.

知识库用于解释 Personal Agent 是如何构建的，让 Owner 在使用过程中同步学习 agent 概念。

## Update Rule

Every new or changed Personal Agent capability should update the relevant Knowledge Base article in the same change, in both English and Chinese.

每次新增或修改 Personal Agent 能力，都必须在同一次变更里更新对应知识文档，并同时提供英文版和中文版。

Each article should cover:
- What we implemented.
- How it works in this project.
- How other common approaches solve the same problem.
- Why this project chose its approach.
- Advantages, disadvantages, and known risks.
- How the capability is evaluated.

每篇文章应覆盖：
- 我们实现了什么。
- 在本项目中如何工作。
- 市面上其他常见方案如何解决同类问题。
- 为什么本项目选择当前方案。
- 优势、劣势和已知风险。
- 如何评测该能力。

## Boundary / 边界

Knowledge Base is not Project Memory. Project Memory helps future Workspace Tasks. Knowledge Base teaches the Owner how the Personal Agent itself works.

Knowledge Base 不是 Project Memory。Project Memory 帮助未来的 Workspace Task；Knowledge Base 用来教学，解释 Personal Agent 本身如何工作。
