# 魔兽世界全版本交互式大地图 (World of Warcraft Interactive Map)

一个基于 Leaflet.js 的独立高性能魔兽世界全版本交互式 Web 大地图应用，完整覆盖 1.0 经典旧世至 11.0 地心之战（The War Within）的所有大陆与核心区域。

---

## 🌟 核心特性

- **🗺️ 全版本大陆覆盖 (1.0 - 11.0)**：
  - **世界总览**：艾泽拉斯全图 (Azeroth)
  - **1.0 经典旧世**：东部王国 (Eastern Kingdoms)、卡利姆多 (Kalimdor)
  - **2.0 燃烧的远征**：外域 (Outland)
  - **3.0 巫妖王之怒**：诺森德 (Northrend)
  - **5.0 熊猫人之谜**：潘达利亚 (Pandaria)
  - **6.0 德拉诺之王**：德拉诺 (Draenor)
  - **7.0 军团再临**：破碎群岛 (Broken Isles)
  - **8.0 争霸艾泽拉斯**：库尔提拉斯 (Kul Tiras)、赞达拉 (Zandalar)
  - **9.0 暗影国度**：暗影界 (Shadowlands)
  - **10.0 巨龙时代**：巨龙群岛 (Dragon Isles)
  - **11.0 地心之战**：卡兹阿加 (Khaz Algar - 最新资料片)

- **🧩 4K 超清大地图算法无缝拼接**：
  - 针对 8.0 及之后的资料片，提取各子区域 1.3x~2.1x 高精细度详图，通过 SIFT 特征匹配与 RANSAC 仿射变换进行反向投影映射。
  - 结合羽化融合算法与有效性遮罩消除拼接黑边，无缝融入暴雪原版手绘海洋与画框纹理。
  - 支持右下角“🧩 模式: 超清大地图 / 📜 模式: 官方原版图”双模式一键切换。

- **🧭 便捷的交互与导航**：
  - **版本大陆下拉切换**：顶部下拉框按资料片层级分组，支持任意版本秒级切换，适配各种屏幕尺寸无水平溢出。
  - **区域平滑聚焦**：支持快速定位至瓦德拉肯、多恩诺嘉尔、伯拉勒斯、达萨罗等各主城及核心区域。
  - **地标与筛选**：内置各大主城、团队副本、五人地下城及交通枢纽标注，支持分类筛选与详情弹窗。
  - **游戏坐标 HUD**：底部实时追踪光标对应地图的魔兽标准 (0-100) 坐标。
  - **层级右键缩放**：支持右键单击平滑返回上级大陆或世界总览。

- **🛡️ 纯净轻量无干扰**：
  - 完全剔除任何音频驱动与权限弹窗，打开即用。
  - 纯前端单页架构，所有资源本地化托管，无需外部网络依赖。

## 🚀 快速启动

在本项目目录下启动任意静态 HTTP 服务器即可：

```bash
cd wow-interactive-map

# 使用 Python 启动
python3 -m http.server 8080

# 或使用 Node.js 启动
npx serve .
```

在浏览器中访问：**`http://localhost:8080`**
