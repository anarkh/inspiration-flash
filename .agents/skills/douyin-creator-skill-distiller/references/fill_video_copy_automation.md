# Fill Video Copy Automation

Use this runbook after the distillation table exists and before generating the final creator skill.

## Purpose

Fill the table's E column (`视频文案`) from the D column (`分享链接`) by submitting each public Douyin video link to a model/browser workflow that can read the video page. The extractor script creates the table shell; this automation fills the transcript/copy cells.

Default batch size: 20 rows. Use smaller batches if the model UI is slow, rate-limited, or unstable.

## Inputs

- Table source: Feishu sheet URL, local `.xlsx`, or CSV generated by `extract_douyin_links.mjs`.
- Required columns:
  - D `分享链接`
  - E `视频文案`
- Optional columns:
  - I `文案状态`
  - J `备注`
- Optional state:
  - last processed row
  - batch size
  - model page URL, usually `https://www.doubao.com/chat/`

Never overwrite a non-empty E cell unless the user explicitly asks to regenerate it.

## Row Selection

For each batch:

1. Read D:E for the active sheet.
2. Select up to `batch_size` rows where:
   - D is a `https://www.douyin.com/video/...` URL.
   - E is empty or whitespace only.
3. Keep original row numbers. Write results back to the same rows.

For Feishu sheets, use the `lark-sheets` skill and `lark-cli sheets +read/+write`. For local workbooks, use the Spreadsheets skill or a structured workbook library. Avoid ad hoc text edits to spreadsheet files.

## Prompt Template

Submit one video link at a time:

```text
{douyin_video_url}

提取上面的视频文案。
要求：
1. 只返回视频中可见/可听到的中文口播、字幕、屏幕文字或商品讲解文案。
2. 尽量保留原顺序和自然分段。
3. 不要总结，不要改写，不要加标题，不要解释。
4. 不要追加“要不要我...”“我可以继续...”之类的建议句。
5. 如果无法读取，直接返回：无法提取：<原因>
```

Use a fresh chat or clear context when previous responses start influencing the output. Wait until the model response is complete before copying text.

## Cleaning Rules

Clean only assistant-added wrapper text; keep the video's own wording.

Remove common leading wrappers:

- `以下是...`
- `视频文案如下：`
- `提取到的文案：`
- Markdown code fences

Remove trailing assistant suggestions from the end of the response, for example:

- `要不要我...`
- `是否需要我...`
- `我可以帮你...`
- `如果你需要，我可以...`
- `需要的话，我还能...`
- `你也可以把...`

Only trim these when they appear as final assistant-added sentences or paragraphs. Do not remove similar wording from the middle of the extracted video copy.

If the result starts with `无法提取：`, write it to J `备注`, set I `文案状态` to `失败`, and leave E empty unless the user wants failure reasons stored in E.

## Write Back

For each successful row:

- Write cleaned copy to E.
- If I exists, write `完成`.
- If J exists, leave blank or write a short note only when useful.

For each failed row:

- Leave E empty.
- If I exists, write `失败`.
- If J exists, write the failure reason.

For skipped/private/deleted videos:

- Leave E empty.
- If I exists, write `跳过`.
- If J exists, explain why.

Write in batches whenever the table API supports it. After writing, read back the same E/I/J cells to confirm the values persisted.

## Batch Verification

After each batch, verify:

- Every successful row has non-empty E.
- No successful E cell ends with a trailing assistant suggestion.
- D links were not changed.
- Row count and row numbers still align.
- Failure/skipped rows have I/J status if those columns exist.

If verification fails, fix the affected rows before moving to the next batch.

## Continuation

For long runs, create a heartbeat automation attached to the current thread:

- frequency: usually hourly
- task: read D:E, find the next batch of rows with D filled and E empty, extract copy, clean, write back, and verify
- stop condition: no remaining D rows with empty E

When the stop condition is reached, delete or pause the heartbeat automation and report completion.

## Completion Criteria

The table is complete when:

- Every row with a D video link has either:
  - non-empty E and status `完成`, or
  - an explicit user-accepted `失败`/`跳过` status with a note.
- There are no model-added trailing suggestion sentences in E.
- A read-back verification confirms the final table state.

Only then proceed to `references/blogger_skill_blueprint.md` to generate the creator skill.
