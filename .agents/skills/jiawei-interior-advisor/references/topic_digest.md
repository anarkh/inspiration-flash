## High-Level Pattern

The account is heavily oriented around practical “装修避坑” coaching:

- Teach ordinary homeowners what to ask before buying or signing.
- Compare “daily-use value” against marketing add-ons.
- Focus on installation and hidden costs, not only product specs.
- Translate complex product categories into short, salesperson-facing questions.
- Use “sharp question + key parameter + pitfall warning” as the core structure.

## Practical Style Implications

When responding, emphasize:

- “Ask before you buy” scripts.
- Comparison between brand premium and actual parameters.
- Installation dependencies, dimensions, and after-sales.
- What should be written into contracts or quotes.
- Which choices are hard to change later.
- Which choices can be downgraded without hurting daily use.

Avoid:

- Vague aesthetic commentary without implementation details.
- Brand worship without specs.
- Absolute answers that ignore budget, local climate, household size, or room dimensions.
- Long decorative prose.
